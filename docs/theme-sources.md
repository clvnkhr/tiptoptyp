# Bundled theme notices

tiptoptyp distributes palettes derived from the projects listed below. The
palette values are embedded in the application; no theme repository is fetched
at runtime. The upstream projects listed here are distributed under the MIT
License unless otherwise stated.

## Attributions

- Solarized — Ethan Schoonover, https://github.com/altercation/solarized
- Gruvbox — morhetz, https://github.com/morhetz/gruvbox
- GitHub theme — GitHub, Inc., https://github.com/primer/github-vscode-theme
- Rosé Pine — Rosé Pine contributors, https://github.com/rose-pine/palette
- Tokyo Night — Folke Lemaitre, https://github.com/tokyo-night/tokyo-night-vscode-theme
- Kanagawa — rebelot, https://github.com/rebelot/kanagawa.nvim
- Everforest — sainnhe, https://github.com/sainnhe/everforest
- Ayu — ayu-theme contributors, https://github.com/ayu-theme/ayu-colors
- Flexoki — Steph Ango, https://stephango.com/flexoki
- Dracula — Dracula Theme contributors, https://github.com/dracula/dracula-theme
- Catppuccin — Catppuccin contributors, https://github.com/catppuccin/palette

Tiptop, Paper, Ocean and Forest are original tiptoptyp palettes and are not
copied from an external palette project.

The bundled light/dark pairs are Solarized Light/Dark, Gruvbox Light/Dark,
GitHub Light Default/Dark Default, Rosé Pine Dawn/Rosé Pine, Tokyo Night Light/
Tokyo Night, Kanagawa Lotus/Wave, Everforest Light/Dark, Ayu Light/Dark,
Flexoki Light/Dark and Dracula Alucard/Dracula. The existing Catppuccin variants
follow the official palette and style guidance. Palette colors are mapped into
tiptoptyp semantic UI and syntax roles; selection and diagnostic translucency
are generated by tiptoptyp rather than copied as separate upstream assets.

## Solarized note

Solarized's upstream repository also includes palette documentation and theme
files under its MIT license. tiptoptyp uses the palette values and does not
redistribute the upstream repository itself.

## Catppuccin note

The Catppuccin palette is MIT licensed. Its style guidance is attribution
material, not executable code, and is not copied into the application.

## Non-theme assets

The package notice generated by `xtask package-build` appends the complete
license text for the pinned Typst and Tinymist binaries, embedded Noto fonts,
and every Rust dependency reported by cargo-about. This source file is the
maintained attribution source for palette material; `THIRD_PARTY_NOTICES` is the
distributed aggregate.
